# 使用指南

## 初始化与账号

首次打开部署地址，按照初始化页面创建系统管理员，使用至少 8 位密码（最长 256 位）。后续使用该账号登录。系统初始化完成后，不能再次通过初始化入口替换管理员。

系统管理员可创建账号、分配角色、停用账号和修改密码。至少保留一个启用的管理员。普通用户注册后使用自己的作品空间，作品和个人设置按账号隔离。

不要把 Cloudflare 管理令牌填入网页 AI 配置；网页只需要模型服务的 API Key。

## 配置 AI

1. 由系统管理员打开 AI 配置，新增档案，填写名称、公网 HTTPS 接口、模型名称与访问密钥。
2. 执行连接验证；验证会发起真实模型请求，可能产生模型费用。
3. 将通过验证的档案分配给剧情规划、章节起草、润色校对等角色。
4. 检查环境页面的数据库、配置和任务能力，再执行小规模试写。

接口应为 OpenAI compatible 服务的基础地址，例如服务商说明中的 `/v1` 地址，不要填写完整的 `/chat/completions` 路径。模型名称以服务商当前支持值为准。

服务端将管理员配置的凭据加密存入 D1。浏览器可见档案元数据，后续使用档案编号请求模型。个人自定义档案和托管档案按当前界面权限管理。

修改已用于长任务的档案地址、模型或密钥后，旧任务可能提示配置变化。保留已有结果，使用当前档案重新提交新任务，避免旧任务静默切换模型。

## 作品与写作流程

1. 新建作品，填写题材、核心创意、故事边界和目标规模，也可导入已有作品。
2. 完善世界观、人物、故事设定和章节计划。预设、灵感和关键词工具用于辅助整理素材。
3. 选择写作流程，生成章节正文，检查结果后再保存或修订。自动流程执行前先核对 AI 角色和章节参数。
4. 使用单章检查、多章检查、全本审查等工具识别问题，按报告执行局部修订或后续创作。
5. 在当前流程允许导出时，生成正文、DOCX 或投稿材料等导出文件。具体导出入口与权限以界面为准。

作品保存到当前部署的 D1；浏览器旧版数据迁移不会直接替换数据库已有作品。出现版本冲突或“其他会话已更新”提示时，先保存当前编辑副本并重新载入，避免从旧标签页继续覆盖。

## 长任务

持久任务支持全本审查 `quality`、关系图谱 `graph`、多章检查 `chapter-batch`、单章检查 `chapter-quality` 和局部修订 `chapter-revision`。

提交时保存正文快照与任务参数。关闭页面后云端任务可继续执行，重新登录可查看状态和结果；本地计算机不需要常驻后台进程。

需要暂停时使用任务操作，等待已发出的模型响应和检查点保存后再续跑。暂停不等于撤销已经发出的模型请求。续跑沿用任务记录与用量，不会因为刷新页面而清空记录。

当前业务层没有累计写作配额拦截；系统仍记录请求和 token 用量，并防止相同步骤并发重复执行。Cloudflare 配额、模型服务限流及费用仍适用。健康检查只能说明入口和绑定可用，任务是否完成应以任务状态及结果为准。

大作品建议先分卷执行，用小样本确认模型、章节长度和检查结果符合预期。

## 管理、诊断与备份

管理员可维护全局参数、管理账号，并在需要时启用诊断日志；默认关闭诊断记录。清理诊断日志不等于删除作品、任务检查点或用量账本。

重要操作前导出作品；系统管理员还可执行系统备份，包含源码、业务数据库 SQL 和运行凭据。备份文件需要按含密码文件保管，不能提交 GitHub。备份和恢复步骤见[运维文档](OPERATIONS.md)。
